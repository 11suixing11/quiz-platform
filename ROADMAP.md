# Roadmap

## Current Priorities

- Keep public copy consistent: 100+ quizzes, self-reflection, not clinical diagnosis.
- Improve metadata, sitemap, OG previews, and static build reliability.
- Reduce generated-code rough edges and lint noise.
- Improve accessibility for quiz flows, result pages, and language switching.

## Later

- Add metadata consistency checks for quiz counts and categories.
- Better result export and sharing previews.
- More careful localization review for English, Chinese, and Japanese.
- A clearer content review process for new quizzes.

## Non-goals

- Clinical diagnosis, therapy, or medical advice.
- Crisis intervention features.
- Collecting sensitive personal data on a backend.
